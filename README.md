# 🎮 GGST Practice Recording Share (길티기어 스트라이브 트레이닝 녹화 공유 모드)

> **만든이**: 남양주빌런 *(제미나이4 아르곤 활용 제작)*  
> **대상 게임**: GUILTY GEAR -STRIVE- (Steam / PC / DirectX 11)

**GGST Practice Recording Share**는 길티기어 스트라이브 인게임 트레이닝(프랙티스) 모드의 **더미 행동 녹화 슬롯(1~5번)** 데이터를 로컬 보관함에 무제한으로 저장·분류하고, **짧은 텍스트 코드(`GGSTREC1:...`, `GGSTSET1:...`) 복사/붙여넣기**만으로 다른 유저와 손쉽게 공유할 수 있게 해주는 인게임 오버레이 모드입니다.

---

## 📥 다운로드 및 설치 방법

👉 **[최신 릴리즈(Releases) 페이지에서 다운로드하기](https://github.com/Lucelion/GGSTPracticeShare/releases/latest)**

스팀 라이브러리에서 `GUILTY GEAR -STRIVE-` 우클릭 → `관리` → `로컬 파일 탐색`을 눌러 아래 경로(`GGST-Win64-Shipping.exe`가 있는 폴더)를 엽니다:
```text
...\GUILTY GEAR STRIVE\RED\Binaries\Win64\
```

본인의 환경에 맞춰 아래 **2가지 패키지 중 하나**만 다운로드하여 압축을 풀어주세요.

### 1️⃣ `GGSTPracticeShare_v1.0.0_All_In_One.zip` (처음 모드를 설치하시는 분 권장)
* `UE4SS` 모드로더가 아직 설치되어 있지 않은 순정 상태의 게임에 사용합니다.
* 압축 파일 안의 내용물(`dwmapi.dll`, `ue4ss` 폴더)을 위 **`Win64`** 폴더에 그대로 복사하여 붙여넣으면 설치가 끝납니다.

### 2️⃣ `GGSTPracticeShare_v1.0.0_Mod_Only.zip` (이미 UE4SS를 사용 중이신 분)
* 프레임 뷰어(`GGSTFrameViewer`) 등으로 이미 `UE4SS`가 설치되어 있는 분께 권장합니다.
* 압축 파일 안의 `ue4ss` 폴더를 `Win64` 폴더에 덮어쓰기 하거나, `GGSTPracticeShare` 폴더를 `Win64\ue4ss\Mods\` 안에 복사합니다.
* `Win64\ue4ss\Mods\mods.txt` 파일을 메모장으로 열어 아래 한 줄이 포함되어 있는지 확인(없으면 추가)하고 저장합니다:
  ```text
  GGSTPracticeShare : 1
  ```

## ✨ 주요 기능

### 1. 인게임 슬롯 1~5 실시간 제어 및 로컬 보관함 (`Recordings.json`)
* 게임 내 5개뿐인 녹화 슬롯의 한계를 넘어, 녹화 데이터를 내 PC 보관함에 **무제한 저장**하고 필요할 때 언제든 원하는 슬롯(1~5번)에 즉시 덮어씌울 수 있습니다.
* **캐릭터 / 제목 / 메모**를 자유롭게 작성하고, 보관함에서 검색 및 정렬(캐릭터순/제목순), **저장 후 정보 수정(`[정보수정]`)**이 가능합니다.

### 2. 📦 세트(슬롯 1~5 묶음) 보관함 및 일괄 교체 (`RecordingSets.json`)
* *"자토 2K-2D 후 샌드위치 정역/중하단 이지선다 세트"*처럼 여러 슬롯을 한 세트로 묶어 저장할 수 있습니다.
* **`[⚡ 슬롯 일괄적용]`** 버튼을 누르면 세트에 지정된 슬롯들은 한 번에 채워지고, **세트에서 비워둔 슬롯은 자동으로 초기화(비움)**됩니다.
* 기존 슬롯에 남아있던 엉뚱한 녹화가 섞이지 않아, 세트 적용 직후 인게임 **'랜덤 재생'** 설정만으로 실전 가드 연습을 즉시 시작할 수 있습니다.

### 3. 📋 문자열 복사 / 붙여넣기 방식의 간편한 코드 공유
* **개별 녹화 코드 (`GGSTREC1:...`)** 및 **세트 녹화 코드 (`GGSTSET1:...`)** 모두 지원합니다.
* 압축(zlib) + Base64 인코딩을 통해 디스코드를 비롯한 메신저, 커뮤니티 게시글, 메모장에 텍스트로 바로 붙여넣어 공유할 수 있습니다.
* 상대방의 코드를 복사(`Ctrl+C`)한 뒤 오버레이의 **`[📋 클립보드에서 코드 붙여넣기 (개별/세트)]`** 버튼을 누르면, 적용 전에 **캐릭터 / 제목 / 프레임 길이 / 메모 / 슬롯 구성 확인 창**이 먼저 표시되어 안전하게 확인 후 보관함 저장 및 슬롯 적용을 동시에 할 수 있습니다.

### 4. ⌨️ 내장 두벌식 한글 입력기 & 단축키 즉시 변경
* **내장 두벌식 한글 오토마타**: 전체화면 등 DirectX 11 환경에서 윈도우 기본 IME가 가로채여도 자체 내장된 두벌식 한글 조합기를 통해 인게임 오버레이에서 한글을 자유롭게 입력할 수 있습니다. (입력창 활성화 상태에서 **`한/영` 키** 또는 **`Shift+Space`**로 전환)
* **단축키 자유 변경**: 기본 열기 단축키는 **`F11`**이며(스팀 스크린샷 키 `F12`와 충돌 방지), 오버레이 우측 상단의 **`[열기 단축키 변경]`** 버튼을 눌러 원하는 키로 즉시 변경(`config.ini` 자동 저장)할 수 있습니다.

### 5. 🔒 프랙티스 모드 전용 안전 하드락 (Anti-Cheat Safety Lock)
* 현재 게임 상태가 **트레이닝(프랙티스) 모드**일 때만 슬롯 제어가 활성화됩니다.
* 온라인 매치, 아케이드, 메인 메뉴 등 프랙티스 모드가 아닌 상태에서는 **하드락(Hard-Lock)**이 작동하여 모든 메모리 읽기/쓰기가 원천 차단됩니다.

## 🛠️ 인게임 사용 요약

1. 트레이닝(프랙티스) 모드에 진입한 뒤 **`F11`** 키를 눌러 오버레이 창을 엽니다.
2. **개별 녹화 저장/공유**:
   * 인게임에서 슬롯(1~5번)에 행동을 녹화한 뒤, 해당 슬롯의 **`[📤 저장 / 공유 코드 만들기]`** 클릭 → 캐릭터/제목/메모 입력 → 보관함 저장 또는 클립보드 코드 복사!
3. **세트(슬롯 1~5 묶음) 저장/공유**:
   * 상단의 **`[📦 현재 슬롯 1~5 묶어서 세트 만들기]`** 또는 하단 **`[📦 로컬 세트 보관함]`** 탭의 **`[➕ 보관함 조합으로 새 세트 만들기]`** 클릭 → 슬롯 1~5 구성 설정 후 저장!
   * 세트 보관함에서 **`[⚡ 슬롯 일괄적용]`** 클릭 시 슬롯 1~5번이 한 번에 교체됩니다.
4. **공유 코드 불러오기**:
   * 공유받은 `GGSTREC1:...` 또는 `GGSTSET1:...` 텍스트를 복사(`Ctrl+C`)한 후 상단 **`[📋 클립보드에서 코드 붙여넣기 (개별/세트)]`** 클릭 → 정보 확인 후 **`[✔ 맞음]`** 클릭!

## 💻 소스코드 빌드 방법 (개발자용)

* **필수 환경**: Windows 10/11 (x64), Visual Studio 2022 (C++ 데스크톱 개발 워크로드), CMake 3.20 이상
* 정적 런타임(`/MT`)으로 빌드되어 타 PC에서도 별도의 VC++ 재배포 패키지 설치 없이 동작합니다.

```powershell
cmake -S src -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```
빌드 완료 시 `build/Release/main.dll`이 생성됩니다.
